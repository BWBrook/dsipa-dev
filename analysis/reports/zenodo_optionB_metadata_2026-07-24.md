## Description

This candidate contains nine processed national Layer A outputs supporting a
detectability-aware assessment of artificial light at night inside and around
Australian protected areas for 2013-2024. It includes annual inside/buffer
radiance summaries, interior-ring profiles, buffer-validity descriptors,
trends, categorical screening output, protected-area descriptors/geometries,
IBRA assignments, and trend-bootstrap summaries.

The payload is the independently accepted Goal 011 concordant non-exact
reproduction. Six files match historical hashes exactly. The radiance table
has no detected primary scientific drift but lacks direct historical row-level
proof; the edge table contains an accepted small threshold-sensitive
difference with current ring-1 feasibility `1,432/12.9%`; and the GPKG has
within-run semantic identity but lacks direct historical feature-level proof.
All accepted primary scientific headlines match.

The legacy file `pa_risk_rankings_v0_3_0.csv` contains categorical screening
output, not a priority ranking.

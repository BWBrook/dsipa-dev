## Build Surfaces

The only profile configuration source is `settings/build.yaml`.

- `draft`: combined working manuscript, 1.5-spaced, including main and
  Supporting Information material.
- `submission`: main text only, double-spaced with continuous line numbering;
  outputs `build/submission/dsipa_rsec_main.{pdf,docx}`.
- `supplementary`: Supporting Information only, with double-spaced portrait
  frontmatter/captions and compact landscape tables; the authoritative
  submission asset is
  `build/supplementary/dsipa_rsec_supplementary.pdf`.

Makedoc also emits `dsipa_rsec_supplementary.docx`, but the dense wide tables
do not lay out readably in that autogenerated file. It is diagnostic build
output, is not a submission asset, and must not be supplied to the journal.

The accepted manuscript science, table headers/cells/values, prose,
references, figure captions/paths, and figure files remain unchanged by Goal
014. Three Markdown table delimiter rows encode reviewed main/SI column
widths. Seven SI image-width attributes preserve complete visible figure
labels: S1-S5/S7 use 85%, and S6 uses 80%.

  running-title counts.
- `cover_letter_draft.md`: non-submittable draft with human confirmation
  markers.
- `declarations_draft.md`: non-submittable declaration prompts.
- `submission_authors.yaml`: visible build placeholders for all unresolved
  author, affiliation, ORCID, and correspondence fields.
- `supplementary_frontmatter.md`: frontmatter for the separate Supporting
  Information profile.
- `supplementary_table_end.md`: PDF-only boundary returning the SI from
  landscape tables to portrait figures.

Every field requiring human knowledge or legal/external authorization is
marked `[BARRY CONFIRM]` or `[PENDING EXTERNAL ACTION]`. Existing repository
metadata is not treated as final submission confirmation.

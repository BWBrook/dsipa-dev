# RSEC Final-Read Candidate

Status: decision-ready for Barry's final read, but explicitly not ready or
authorized for Wiley submission. Do not submit, upload, create an external
record, accept fees, or agree to licence/open-access terms from this folder.

Journal: *Remote Sensing in Ecology and Conservation*

Article type: **Original Research**

Title:

> Detectable change in dark-sky integrity across Australia’s protected areas

## Build Surfaces

The only profile configuration source is `settings/build.yaml`.

- `draft`: combined working manuscript, 1.5-spaced, including main and
  Supporting Information material.
- `submission`: main text only, double-spaced with continuous line numbering;
  outputs `build/submission/dsipa_rsec_main.{pdf,docx}`.
- `supplementary`: Supporting Information only, with double-spaced portrait
  frontmatter/captions and compact landscape tables; the authoritative
  submission asset is
  `build/supplementary/dsipa_rsec_supplementary.pdf`.

Makedoc also emits `dsipa_rsec_supplementary.docx`, but the dense wide tables
do not lay out readably in that autogenerated file. It is diagnostic build
output, is not a submission asset, and must not be supplied to the journal.

Goal 016 leaves the accepted science, table headers/cells/values, references,
figure paths, and figure files unchanged. Its bounded prose changes disclose
the Table S1 and Figs S2-S3 top-N selection rules, identify each Layer B
shuffle as one deterministic seeded illustrative realisation rather than a
sampled null distribution, compress repeated Layer B caveats modestly, and
distinguish internal engineering quality from public reproducibility.
